# Références et recettes UI

Les sous-dossiers conservent les captures et scripts des jalons, variantes et
contrôles ciblés. Une preuve décrit sa date, sa version et son environnement ;
elle ne démontre pas à elle seule le comportement d’une version ultérieure.

- [Identité atelier](identite-atelier.md) : direction visuelle validée.
- [Validation issue #39](validation-issue39.md) : Chrome/Zen, zoom, clavier et limites.
- [Catalogue actuel](../catalogue-ui.md) : parcours livré et références aux onglets.
- [Recette métier](../recette-metier.md) : matrice et journal historiques.
- [Livraison NAS](../livraison-nas.md) : validation ciblée sur l’environnement final.

Les anciens essais conservés ne sont pas des travaux à refaire automatiquement.
Le code courant et les parcours actifs priment sur les captures d’une variante
abandonnée. Ne pas ajouter de capture contenant des données clientes réelles.
